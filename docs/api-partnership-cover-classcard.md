담당자님께,

클래스카드, 클래스5, 오토보카는 한 회사에서 운영되지만 **학습 리포트는 서비스별로 따로** 제공됩니다. 학부모 입장에선 같은 회사의 세 리포트조차 흩어져 있어 아이의 어휘·학습 현황을 한 번에 보기 어렵습니다.

**Plantor는 이 세 서비스를 하나의 학부모 대시보드로 묶는 것을 첫 우선 파트너십으로 제안드립니다.**

이 조합이 귀사에 특히 유리한 이유:

- **단일 연동, 3배 노출:** 계정 체계가 공유된다면 **하나의 OAuth/API 연동**으로 세 서비스 리포트를 함께 표출 → 개발 부담은 한 번, 학부모 노출은 3개 브랜드
- **크로스셀 유도:** 클래스카드만 쓰던 학부모에게 클래스5·오토보카 리포트 자리(및 "시작하기" 딥링크)를 함께 노출 → **자사 서비스 간 교차 유입**
- **재구독 방어:** 세 서비스의 학습 성과가 한 화면에 누적 표시 → 학부모의 학습 효과 체감 극대화

우선 **가장 데이터가 정리된 한 서비스(예: 오토보카 어휘 리포트)로 파일럿**을 진행하고, 검증 후 나머지 둘로 확장하는 단계적 방식을 제안합니다.

세부 요청 범위·연동 방식·개인정보 보호 약속은 첨부된 본 제안서를 참고 부탁드리며, **30분 미팅**을 통해 세 서비스의 계정·리포트 구조에 맞는 최적 연동안을 함께 잡고 싶습니다.
