## 수집 팁

1. **이미지 TOC가 대부분**: 텍스트 추출이 안 되므로 캡처 후 직접 옮겨 적는 게 가장 빠릅니다.
2. **PDF 우선**: 출판사가 PDF로 차례나 견본을 제공하면 그쪽이 OCR 가능해 작업이 빠릅니다.
3. **자습서 검색이 보조**: 출판사 사이트에서 안 찾아질 때 "[출판사][과목][학년] 자습서" 검색하면 학원/문제집 사이트에서 단원명을 미리 정리해둔 곳이 있습니다.
4. **나무위키 보조**: 일부 교과서는 나무위키에 단원명이 정리돼 있습니다(예: 2022 개정 교육과정/[과목]/[학년] 페이지).
