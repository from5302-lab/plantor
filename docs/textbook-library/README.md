# 교과서 단원 라이브러리

중학교~고등학교 (중1~고3) 교과서 단원명을 출판사·교육과정·과목별로 정리한 JSON 데이터베이스와 웹뷰어입니다.

## 폴더 구성

```
textbook-library/
├── index.html         # 웹뷰어 (단일 파일, fetch로 JSON 로드)
├── schema.json        # books.json의 JSON Schema
├── data/
│   ├── books.json     # 메인 데이터 (단원명 라이브러리)
│   ├── publishers.json# 학년·과목별 출판사 참고 목록
│   └── toc-sources.md # 확인된 출판사 TOC 이미지/페이지 URL 모음
└── README.md          # 이 문서
```

## 빠른 사용법

### 로컬에서 보기

```bash
cd textbook-library
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

`file://`로 직접 열면 `fetch()`가 CORS 정책에 막힙니다. 반드시 로컬 서버를 통해 열어야 합니다.

### 웹에 배포

이 폴더를 그대로 정적 호스팅에 올리면 됩니다. 옵션:
- **GitHub Pages**: 레포에 push → Settings → Pages → `main` 브랜치 루트 선택
- **Netlify / Vercel**: drag & drop 또는 git 연동
- **S3 + CloudFront**: 정적 사이트 호스팅 설정
- **Notion / Google Sites**: 임베드(iframe)로 삽입 가능

배포된 URL을 다른 웹서비스에서 fetch하면 데이터를 가져갈 수 있습니다(CORS 헤더 설정 필요).

### JSON 직접 사용 (다른 앱에서)

```js
const res = await fetch('https://your-host/textbook-library/data/books.json');
const lib = await res.json();
const m1Korean = lib.books.filter(b => b.grade === '중1' && b.subjectGroup === '국어');
```

- 미래엔 자습서 ([eduteacher.mirae-n.com](https://eduteacher.mirae-n.com)): "교재 목차 보기" 섹션에서 국·영·수·사·과·역 전과목 추출
- NE능률 NE Books ([m.nebooks.co.kr](https://m.nebooks.co.kr)): "내용 펼치기" 클릭 시 영어 교과서 목차 표시
- YBM Y클라우드 ([ybmcloud.com](https://www.ybmcloud.com/textbook/)): 영어·수학·과학 책 단원별 수업안 페이지에 대단원 텍스트
- 영어과외TV ([englishtutortv.com](https://englishtutortv.com)): 동아·비상·천재·지학사 등 거의 모든 출판사의 영어 단원명을 본문 제목까지 정리
- **수학카페** ([mathcafe.co.kr/9](https://mathcafe.co.kr/9)): 중1·2·3 수학 표준 단원 전체를 텍스트로 정리 (2022 개정)
- **나무위키 교육과정 페이지** (예: namu.wiki/w/2022_개정_교육과정/과학과/중학교/과학_1): 교육과정 표준 단원명

**시드 데이터 정책**
- ✓ (verified): EXAM4YOU·미래엔 자습서·YBM 등 출판사 1차 자료에서 직접 확인. 책 ID·저자·단원·본문 제목 정확.
- ≈ (baseline): 교육과정 표준 단원 (mathcafe + namu wiki)을 출판사에 일괄 시드. 대단원은 정확하지만 출판사별 중·소단원 미세 차이는 별도 확인 필요. verified:false로 표시.

**가장 큰 빈 칸**
- 중3 전체 (2015 개정): 마지막 해라 출판사 온라인 자료가 거의 정리되어 있지 않음

## 데이터 확장 방법

### 1) JSON에 새 책 추가하기

`data/books.json`의 `books` 배열에 객체를 하나 추가합니다.

```json
{
  "id": "kor-m1-chunjae-2022-noh",
  "subject": "국어",
  "subjectGroup": "국어",
  "grade": "중1",
  "schoolLevel": "middle",
  "curriculum": "2022",
  "publisher": "천재교육",
  "publisherCode": "chunjae-edu",
  "authors": ["노미숙 외"],
  "approvalYear": 2024,
  "useYear": 2025,
  "sourceUrl": "https://text.tsherpa.co.kr/mid/book.html?bookcode=text-mid-korean-nms",
  "sourceType": "publisher-site",
  "verified": true,
  "units": [
    {
      "level": 1, "number": "1", "title": "대단원 제목",
      "subunits": [
        {"level": 2, "number": "(1)", "title": "중단원 제목", "page": "12",
          "subunits": [
            {"level": 3, "number": "①", "title": "소단원 제목", "page": "14"}
          ]
        }
      ]
    }
  ]
}
```

필수 필드: `id`, `subject`, `grade`, `schoolLevel`, `curriculum`, `publisher`, `units`.
선택 필드: `subjectGroup`, `authors`, `approvalYear`, `useYear`, `isbn`, `sourceUrl`, `verified`, `notes`.

### 2) ID 명명 규칙 (권장)

`<과목코드>-<학년코드>-<출판사코드>-<교육과정연도>[-구분]`

- 과목코드: `kor`(국어), `eng`(영어), `math`(수학), `soc`(사회), `sci`(과학), `hist`(역사), `klit`(문학), 등
- 학년코드: `m1`/`m2`/`m3`/`h1`/`h2`/`h3`
- 출판사코드: `publishers.json`에 있는 `code`
- 교육과정연도: `2022` 또는 `2015`
- 구분(선택): 대표저자 약어 등 (예: 미래엔 국어 신유식본 → `-shin`)

예: `kor-m1-mirae-2022-shin`, `math-h2-visang-2022`

### 3) 검증 워크플로

1. **출판사 사이트 1순위** (publishers.json에 URL 정리됨)
2. 사이트에서 책 → "차례" 탭 → 이미지 캡처 또는 PDF 다운로드
3. 단원명 옮기기 → `verified: true`로 저장
4. 사이트에 없는 경우 PDF 정오표, 교사용 자료실 보조 활용

### 4) 점진적 확장 추천 순서

이번 세션에서 수집한 미래엔 국어1-1을 따라 **같은 출판사의 다른 책**을 먼저 채우면 사이트 익숙도 덕에 가장 빠릅니다.

권장 순서:
1. 미래엔 중1 전과목 (영어1, 수학1, 사회①, 과학1)
2. 미래엔 중2 전과목 (자동으로 2022 개정)
3. 천재교육 중1 전과목 (사이트가 익숙해진 뒤)
4. 비상교육 → 동아출판 → NE능률 → 지학사 순
5. 중3 (2015 개정 - 별도 사이트일 수 있음)
6. 고등학교 공통과목 → 일반선택

## 알려진 한계 / 주의사항

- **출판사 사이트의 차례가 이미지 단일 JPG/PNG로 제공되는 경우가 많습니다.** 텍스트 추출이 안 되어 수동 전사가 필요합니다.
- **JS 무한 로딩**: 일부 출판사 포털(예: 미래엔 22txbook)은 페이지가 "유휴(idle)" 상태가 되지 않아 자동화 도구가 멈춥니다. 그럴 땐 직접 캡처/전사가 빠릅니다.
- **검정·인정 출판사 목록은 매년 변동**됩니다. `publishers.json`은 참고용이며 최종 확인은 한국교육과정평가원([tbh.kice.re.kr](https://tbh.kice.re.kr/inf/if001List.do))과 한국교과서협회([ktbook.com](https://www.ktbook.com))를 참고하세요.
- **고등학교 일반선택**은 출판사 종류가 더 많고 사용 학교가 다양해서 책택 빈도가 낮은 책은 자료가 부족할 수 있습니다.

## 웹뷰어 기능

- 검색: 출판사·단원명 자유 검색
- 필터: 교육과정(2022/2015) / 학년 / 과목군 / 출판사
- 책 카드 클릭 → 모달로 대/중/소단원 트리 표시
- `verified: false`인 책에는 "미확인" 칩 표시

## 라이선스 및 출처

- **단원명·교과서 메타데이터**: 각 출판사가 저작권을 보유. 이 라이브러리는 참고/색인 목적으로 정리한 것이며, 실제 교과서 본문을 포함하지 않습니다.
- **데이터 출처**: 각 책의 `sourceUrl` 필드에 출판사 사이트 또는 공식 자료 URL 명시
- **공식 출처**:
