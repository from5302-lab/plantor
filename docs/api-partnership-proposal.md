## 1. 한 문단 요약 (Executive Summary)

오늘날 한 아이는 어휘 앱, 수학 앱, 독서 플랫폼 등 **평균 3~5개의 에듀테크**를 동시에 사용합니다. 하지만 학습 리포트는 서비스마다 따로 나오기 때문에, 학부모는 아이의 전체 학습 상태를 한눈에 파악하지 못합니다. **Plantor**는 각 에듀테크의 학습 리포트를 학부모 **본인 동의** 하에 모아 하나의 대시보드로 보여주는 서비스입니다. 이 제안서는 귀사의 학습 리포트 데이터를 **읽기 전용 API**로 연동하기 위한 협업 조건과 기술·보안 사항을 담고 있습니다.

---

## 2. 해결하려는 문제

- **학부모:** 서비스마다 앱을 열고, 로그인하고, 리포트를 따로 확인해야 함 → 대부분 방치됨
- **에듀테크:** 학부모가 리포트를 잘 안 보면 → **학습 효과 체감 저하 → 재구독/재계약률 하락**
- **공통:** 흩어진 데이터는 "우리 서비스가 실제로 도움이 된다"는 근거를 학부모에게 전달하지 못함

> Plantor는 이 마지막 마일(학부모 도달)을 대신 책임집니다.

| 파트너 혜택 | 설명 |
|---|---|
| **재계약률 상승** | 학부모가 귀사 리포트를 더 자주·꾸준히 확인 → 학습 효과 체감 → 이탈 방지 |
| **추가 노출 채널** | Plantor 대시보드에서 귀사 로고·브랜드·"자세히 보기" 딥링크 노출 (귀사 앱으로 트래픽 유입) |
| **비용 0 마케팅** | 리포트 옆에 귀사의 강점(예: 어휘 향상률)이 그대로 표출 → 학부모 대상 무료 홍보 |
| **데이터 주권 유지** | Plantor는 데이터를 **읽기만** 합니다. 저장·판매·재가공·타사 공유 없음. 언제든 연동 중단 가능 |
| **개발 부담 최소** | 신규 API 구축이 부담이면, 기존 학부모 리포트 엔드포인트/CSV/파일 export부터 시작 가능 |

**핵심:** 이 제휴는 귀사의 데이터를 **가져가는** 것이 아니라, 귀사의 가치를 **학부모에게 더 잘 전달**하는 유통 채널입니다.

## 4. 요청 범위 (What We Request)

학부모가 **본인 자녀에 한해**, **본인이 명시적으로 동의**한 경우에만 아래 데이터를 읽습니다.

**필수(Minimum) 필드**
- 학생 식별자 (귀사 내부 ID 또는 가명화된 토큰)
- 학습 기간 / 최근 학습일
- 과제·미션 완료율, 진도율
- 정오답률 / 정확도 등 핵심 성취 지표
- 리포트 원본으로 이동하는 **딥링크 URL**

**선택(Optional) 필드**
- 학습 시간(누적/일별)
- 영역별 상세 지표(어휘·독해·연산 등)
- 성취 뱃지 / 레벨

> 우리는 **개인정보를 최소로만** 요청합니다. 위 목록은 협의로 조정 가능하며, 처음엔 최소 필드만으로 시작해도 좋습니다.

## 5. 연동 방식 (Integration Options)

귀사 상황에 맞춰 아래 중 하나부터 시작할 수 있습니다. **가장 부담 적은 방식을 택하시면 됩니다.**

1. **REST API + OAuth 2.0 (권장)**
   - 학부모가 귀사 계정으로 로그인 → 동의 → Plantor에 `read-only` 토큰 발급
   - 데이터 주체(학부모)가 직접 권한을 주고, 언제든 회수 가능한 표준 방식
2. **API Key + 학부모 동의 증빙 전달**
   - 서버 간 통신, 학부모 동의 로그를 Plantor가 보관·제공
3. **Webhook / 정기 배치(파일·CSV) Export**
   - 실시간 API 구축이 부담일 때, 하루 1회 요약 데이터 전달부터 시작
4. **파일럿(수동) 연동**
   - 소수 학부모 대상 CSV로 개념 검증(PoC) 후 정식 API로 확장

**공통 규격 제안**
- 프로토콜: HTTPS / TLS 1.2+
- 포맷: JSON (UTF-8)
- 인증: OAuth 2.0 (Authorization Code) 또는 발급형 API Key
- 호출: 학생당 1일 수 회 수준의 저빈도 폴링 (Rate limit 준수, 캐싱 적용)

## 6. 개인정보 · 보안 약속 (Trust & Compliance)

귀사가 가장 신경 쓰실 부분입니다. Plantor는 다음을 **계약서에 명시**합니다.

- **법적 근거:** 개인정보보호법을 준수하며, 만 14세 미만 아동 데이터는 **법정대리인(학부모) 동의**를 기반으로만 처리
- **최소 수집:** 리포트 표시에 필요한 최소 항목만 요청, 민감정보 미수집
- **읽기 전용:** 데이터 수정·삭제·재판매·제3자 공유·광고 타깃팅 **일절 없음**
- **암호화:** 전송 구간 TLS, 저장 시 암호화 및 접근 통제 로그
- **동의 관리:** 학부모가 Plantor에서 언제든 연동 해제 → 즉시 토큰 폐기·데이터 삭제
- **투명성:** 처리위탁/제3자 제공 관계를 문서화하고, 필요 시 데이터처리계약(DPA) 체결
- **감사 대응:** 귀사 요청 시 접근 로그·처리 내역 제공
